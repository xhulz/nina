## Integration docs (load whenever an external service is touched)

Each file in `.claude/integrations/` captures verified runtime premises about a dependency. The architect MUST cite premises from these docs (or new ones it verifies with `node_modules/.pnpm/<lib>/...:<line>` references) in any spec that touches the integration surface. The integration-tester probes each cited premise (for {{PROVIDER}}, against the contract suite and the live sandbox) before the reviewer can approve.

New docs are generated by the integration-tester probing the **real installed source** under `node_modules/.pnpm/<lib>@<version>/...`, so premises are version-accurate from day one.

When you discover a new behavior for any dependency, append it as a premise to the relevant `.claude/integrations/<lib>.md`, **creating the file if absent** with a fresh `node_modules:<line>` citation against the version actually installed in this repo.
